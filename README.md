# Sales & Business Performance Dashboard

## Project Overview

The Sales & Business Performance Dashboard is a data analytics project developed using Microsoft Power BI and Excel. The main objective is to analyze sales data, monitor business performance, identify profitable products, and understand customer purchasing behavior.

The dashboard presents interactive visualizations and key performance indicators (KPIs) that help businesses make better data-driven decisions.

## Tools and Technologies Used

- **Microsoft Excel** – Dataset storage and initial data handling.
- **Power BI Desktop** – Dashboard development and data visualization.
- **Power Query** – Data cleaning, transformation, and preprocessing.
- **DAX (Data Analysis Expressions)** – Creating calculated measures and KPIs.

## Methodology

The project follows these steps:

### 1. Data Collection
- Used an Excel dataset named `Sales_Data`.
- Imported the sales data into Power BI Desktop.

### 2. Data Cleaning and Preprocessing
- Used Power Query to inspect and prepare the dataset.
- Checked data types and column consistency.
- Prepared the data for analysis and visualization.

### 3. Data Analysis
- Analyzed sales and profit performance.
- Compared sales across different product categories and regions.
- Identified top-performing products, customers, and salespersons.
- Examined monthly sales trends and customer purchasing patterns.

### 4. DAX Calculations
Used DAX measures to calculate important business KPIs, including:
- Total Sales
- Total Profit
- Category with Highest Sales
- Region with Highest Profit
- Customer and Salesperson Performance

### 5. Dashboard Development
Created a three-page interactive Power BI dashboard using KPI cards, charts, tables, and other visualizations.

## Dashboard Pages and Features

### Page 1 – Sales Overview
- Total Sales KPI
- Total Profit KPI
- Monthly Sales Trend
- Sales by Category
- Sales by Region
- Top-Selling Category
- Best-Performing Region

### Page 2 – Product and Regional sales
- Top 10 Products by Profit
- Sales by Salesperson
- Product performance analysis
- Profitability comparison

  ### Page 3 – Customer and salesperson analysis
- Top 5 Customers
- Customer Purchase Distribution
- Customer Segmentation (New and Returning Customers, where available)
- Customer purchasing behavior analysis

## Key Performance Indicators (KPIs)

- Total Sales
- Total Profit
- Highest-Selling Category
- Highest-Profit Region
- Top Customer
- Top Salesperson
